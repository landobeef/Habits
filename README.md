# HabitPulse - Personal Habit Tracker

A lightweight, private, self-contained Progressive Web App (PWA) habit tracker.

## How to Enable GitHub Pages (Free Hosting)
1. In your GitHub repository, click **Settings** (top right tab).
2. In the left sidebar, click **Pages**.
3. Under **Build and deployment** -> **Branch**, select  (or ) and folder .
4. Click **Save**.
5. Wait ~30 seconds, and refresh the page. GitHub will show your live URL:
   

## How to Install on Phone
1. Open the GitHub Pages URL in **Safari** (iPhone) or **Chrome** (Android).
2. Tap **Install App** or **Add to Home Screen**.
3. All habits and logs are saved privately in your phone's browser storage.
